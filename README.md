# Snake3D Game

## About the Project

Snake3D is a JavaFX-based desktop game that brings the classic Snake experience into a 3D environment. Players control a snake, collect fruits, avoid obstacles, and compete against AI-controlled enemy snakes while aiming for the highest score.
Note: It is Desktop Application
## Features

- 3D snake rendering using JavaFX
- Multiple AI-controlled enemy snakes
- Intelligent pathfinding system
- Fruit collection and score tracking
- Special power-up items
- Sound effects and background media
- Smooth animations and visual effects
- Game Over and restart functionality

## Technologies Used

- Java
- JavaFX
- Object-Oriented Programming
- BFS-based AI Pathfinding
- Audio and Media Components

## How to Run

### Requirements

- Java 17+
- JavaFX SDK

### Steps

1. Clone the repository.
2. Open the project in IntelliJ IDEA or Eclipse.
3. Configure JavaFX SDK.
4. Build and run `Main.java`.

## Controls

- Arrow Keys → Move Snake
- Collect fruits to increase score
- Avoid collisions
- Compete against AI snakes
